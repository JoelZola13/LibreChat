# Tiptap Open-Source Feature Audit

Last updated: May 4, 2026

## Scope

This audit maps the official Tiptap 3.x documentation against our `/documents` editor. It treats the open-source Editor and open-source Editor extensions as the target surface. It does not treat Tiptap Cloud, Start Plan, Team Plan, or Add-on features as open source.

## Current Coverage

Implemented in `/documents`:

- Core React editor: `@tiptap/core`, `@tiptap/react`, `@tiptap/starter-kit`.
- StarterKit document model and common editing behavior: document, text, paragraph, heading, blockquote, horizontal rule, hard break, bold, italic, code, strike, dropcursor, gapcursor, undo/redo, and trailing node. ListKit owns list nodes/keymaps, CodeBlockLowlight owns code blocks, and dedicated extensions own links and underline.
- Toolbar-visible core controls: undo, redo, paragraph, heading 1, heading 2, heading 3, blockquote, code block, horizontal rule, bold, italic, inline code, strike, links, bullet list, ordered list, plus a Notion-style `Turn into` block transform menu.
- Additional open-source extensions already wired: highlight, text align, placeholder, character count, selection preservation, focus styling, official ListKit lists/checklists, tables, images, YouTube embeds, audio embeds, Twitch embeds, typography, subscript, superscript, text style kit, details, emoji, mathematics, mentions, invisible characters, file handler, drag handle, unique IDs, official table of contents data, syntax-highlighted code blocks, bubble/floating menus, Markdown beta, collaboration, and collaboration caret.
- Rich table editing: the toolbar now exposes a compact Tiptap table tools menu with insert table, add row above/below, delete row, add column left/right, delete column, merge cells, split cell, toggle header cell, toggle header row, toggle header column, and delete table commands.
- Rich inline editing: selected text now opens a Tiptap BubbleMenu surface with bold, italic, underline, strike, inline code, highlight, link, unlink, comment, text color swatches, and background color swatches.
- Rich empty-block editing: empty paragraphs now expose a broader Tiptap FloatingMenu quick-insert tray for text, headings, lists, checklist, quote, callout, code block, divider, details, table, image, YouTube, audio, Twitch, and mention commands.
- Notion-style command discovery: the editor now has a slash-command menu powered by Tiptap's open-source Suggestion utility. Typing `/` at the start of a block exposes text, heading, list, checklist, quote, code, divider, table, details, math, emoji, mention, image, YouTube, audio, and Twitch actions with keyboard and mouse selection. The slash menu is grouped into Basic blocks, Lists, Structure, Inline, and Media categories, shows compact `/command` hints, and keeps command-only keyboard selection across category headers. The toolbar also has a `Turn into` menu for converting the current block into text, headings, quote, callout variants, code, lists, checklist, details, divider, or table. The drag-handle block actions menu can select the current block, open a block-scoped comment composer, copy a deep link to the block, apply block text/background swatches, insert a blank block above/below, duplicate, delete, move, or transform the current block directly beside the page content. Block links use Tiptap UniqueID node attrs plus a `documentId` URL parameter so reopening a link restores the document and highlights the target block.
- Custom app-layer equivalents: comments, tracked-change suggestion marks, autosave, local offline drafts, page setup metadata, print preview, templates, Markdown/HTML/DOCX export calls, and app-owned Notion-style callout blocks.
- App-owned version recovery: the editor now records local Tiptap JSON snapshots after successful saves, mirrors those snapshots into a Mongo-backed `/api/documents/history` durable snapshot store when the LibreChat backend is reachable, merges them with the server version endpoint when available, opens Version History from the editor toolbar and document context menu, can restore a snapshot through the document API, and can export/import the local snapshot ledger as a JSON backup.
- Infrastructure-backed collaboration: `/api/documents/collaboration/:room` now speaks the Yjs/y-websocket protocol with rooms, room-scoped awareness updates, heartbeat cleanup, one room per document, room-name validation, scoped room tickets, short-lived edit-lock leases, document-level permission checks before ticket issuance/lock acquisition, payload limits, per-room connection caps, optional Redis pub/sub fanout across backend instances, Yjs snapshot persistence through either local files or Mongo-backed `DocumentsCollaborationSnapshot` records, and an awareness-backed presence menu that shows local/remote editor mode. This is real multi-client sync with same-process operation by default, optional cross-process relays when Redis fanout is enabled, and restart survival through the configured persistence provider.
- Local document organization: `/api/documents/organizer` now scans configured local roots for document-like files, stores metadata-only records in MongoDB, classifies them into virtual folders by file type, and renders a Local Organizer panel in `/documents`. It also previews collision-safe physical folder moves into `DOCUMENTS_ORGANIZER_PHYSICAL_ROOT`, defaults physical moves to `Documents`, `Desktop`, and `Downloads` while leaving `Projects` virtual, excludes structured data from physical moves by default, and only applies moves after the in-app `MOVE FILES` confirmation.

## Open-Source Extension Checklist

### Covered

- Nodes: audio, blockquote, bullet list, code block lowlight, details/details content/details summary, document, emoji, hard break, heading, horizontal rule, image, list item, mathematics, mention, ordered list, paragraph, table/table cell/table header/table row, task item, task list, text, Twitch, YouTube, plus the app-owned `streetbotCallout` node.
- Marks: bold, code, highlight, italic, link, strike, subscript, superscript, text style, underline.
- Functionality: background color, bubble menu, character count, color, drag handle, dropcursor, file handler, floating menu, focus, font family, font size, gapcursor, invisible characters, line height, list keymap, list kit, Markdown beta, placeholder, selection, starter kit, table kit, table of contents, text align, text style kit, trailing node, typography, undo/redo, unique ID, and Suggestion-backed slash commands.
- App equivalents: comments and tracked changes through app-owned review records.

### Missing Or Partial

- Backend/UI-dependent: collaboration/carets are wired through a Yjs websocket server with scoped room tickets, document-level permission checks, edit-lock leases, optional Redis fanout, file or database snapshot persistence, local draft recovery, conflict handling, presence policy, and resource guardrails; pasted/dropped media now prefers authenticated durable file storage with explicit size limits and only allows tiny inline image fallback; drag handles now expose stable QA attributes, target metadata, and verified move-up/move-down controls, with native browser drag/drop still needing manual pointer/touch confirmation.

## Not Open Source In The Tiptap Docs

These should not be counted as free OSS coverage:

- AI Generation, AI Toolkit, Server AI Toolkit.
- Official Comments extension/service.
- Official Import and Export conversion features.
- Official Pages extension.
- Paste Handler.
- Snapshot Compare.
- Official Tracked Changes add-on.
- Version Starter.

We can still build app-owned alternatives for some of these, and we already started doing that for comments, tracked changes, page settings, and import/export routing.

## LibreOffice Decision

For an OSS-first documents app, keep LibreOffice available. Tiptap's open-source editor is enough for native authoring, but official high-fidelity import/export/conversion is not in the free OSS bucket. LibreOffice remains useful for private/self-hosted DOCX, ODT, and PDF workflows behind a pluggable conversion service.
